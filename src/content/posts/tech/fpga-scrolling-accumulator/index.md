# 数电实验—fpga实现加法上亿的计算器


想法过程：
本来一开始摆烂，结果室友发现可以用16进制来存储，实现加和到31的加法器
开始思考了，能不能加的更多
我瞬间想到了可以通过储存位数，来相加更多的数字，如从a+b到a+b+c
但是这样只能实现加到99（10进制）
进一步思考，能不能加到100以上，我想到两条思路，可以通过滚动数字屏幕实现，也可以通过16进制编码实现，但是16进制编码我们人类阅读困难，而且也很容易到极限。那也就是个16^ 2而已
我的室友想到可以第一个数码管储存位数，第二个数码管显示数字，这样可以扩展到10的9次方，这个方法可以，能上亿，但是缺点就是不直观，一个人过来还得了解你这个规则才行，需要解码，不过仍然好办法。

为了加的更多，如果简单的线性加和，只能加8个数字，只能加到120，实在是不太符合计算器，室友提示说是可以把led进行二进制编码，这样至少可以实现2的8次方-1个数字相加了。
其实从最终结果可以看出，这个东西可以实现更复杂的计算器，已经远远超过实验要求的设计个加法器。
在一个小板子上，只有两位数码管，能实现这样的功能已经很难得了
大家好，我来简单介绍一下我们做的加法器实验的扩展内容，拨码开关实现初始输入数据，四个按键有不同的功能，从上往下看，第一个按键，是寄存器按键，我们用它来实现开始输入数据的功能，第二个按键，是储存器按键，我们用它来实现存储，同时会亮起led，通过读取led的位置，我们可以知道加到第几位了，第三个按键，是加和按键，直接计算出结果，第四个按键是复位按键
当我们计算的结果超过100了，数码管无法显示，因此，我们重载了第一位按键，实现了滚动屏幕的功能，按第一个按键，就能看到完整的数字了。
在这同时，还可以继续相加，我们在这个基础上加到2025，来结束这个实验，纪念一下2025这个时刻

这个的极限在哪：首先只有2位数码管，我们可以让前一位显示位数，后一位显示数字：
就是一个是位数，一个是当前的数字，比如1 0 ；2 1就是现在是十位，数字显示1；同样的9 1就是现在是第九位，数字显示1，这种压缩的话，我记得那个是两位的数码管，那最大显示99就是9位数，显示9；还不是4位，是两位

按键可以重载，可以回滚好像，就是按一下就往后显示一个那种位数

实际上这个用滚动窗口能实现无穷大的，一直滚，滚到最后就—-就行

# 多agent协同

agent分布
1.揽客agent 类似拉客户的，可以从小红书或者社交媒体吸引过来，主动投放广告等等 在小红书、抖音、美团等平台寻找潜客。

2.店内交互agent  类似店员 在用户进入小程序或实体店后，完成“临门一脚”的下单。

3.会计agent 帮助计算流动资金，把需求什么的发给主管，来提供采购数据和建议等等 不直接面对客户，专门负责算账和调配。

老字号的问题是年轻人不知道这个老字号和品牌效应在减弱。我认为的问题是扩大宣传力度。

把相关产品做成数字藏品，供agent从各个方面可以讲解
 * **复活“老掌柜”**：通过多模态 AI，让老字号的创始人或历史人物以“智能体”身份出现在社交平台和实体店屏幕。
 * **新中式混搭建议**：智能体通过分析当前的流行趋势（如“新中式穿搭”），主动建议用户如何将传统产品融入现代生活。
 * **非遗数字化**：将枯燥的非遗工艺录入向量数据库，智能体能随时解答任何硬核的技术细节，树立“专业壁垒”。

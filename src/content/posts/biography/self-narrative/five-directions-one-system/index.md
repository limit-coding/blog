# 个人发展的五大方向

本质上这五个方向是一个方向，都是研发系统，只不过领域不一样，包括控制论


* **系统架构设计**（原AI infra）：字节实习练的分布式系统、状态管理、可观测性，这些能力可以用在任何大规模系统上——AI平台、卫星地面站系统、星座调度系统，都用得上，不再局限于"AI"这个标签
* **CUDA底层优化**：偏硬件性能优化的技能，跟系统架构设计是互补关系（一个管"整体怎么协同"，一个管"单点怎么榨干性能"）
* **芯片前端设计/FPGA解调**：硬件层，卫星通信本行
* **计算机网络**：连接层，尤其DTN方向
* **具身智能**：算法/场景层

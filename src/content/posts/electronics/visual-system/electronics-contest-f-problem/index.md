# 电赛F


思路分析

大概就是信号源发一个确定的信号x 1k-100khz 然后fpga等信号发生器输出一个信号y

x和y要搭配一个李萨如图形
第五问是关于视觉的，需要用摄像头拍照识别，然后拍这个图形有三种，一种是直线，一种是椭圆/圆，一种是八字
这个困难的地方是fpga发出的信号有频偏和相偏

然后需要锁相环可能，不然那个图形一直在旋转


然后就是步进的过程中，如果基准频率低，那么这个圆旋转的快，如果高，就还好，所以需要控制fpga扫频的精度来闭环控制

现在考虑的关键就是怎么在fpga扫频的时候摄像头识别，这个帧率抓拍稳定吗

考虑我们硬件豪华，dds啥的都有我们是zynq 7020+树莓派5 16GB 摄像头准备用ov2735验证 正式用camera3 module 能自动校准焦距

考虑的问题，识别速度和树莓派和fpga通信时延，要求稳定3s 控制时间10s

我看第五问的意思是让fpga根据x发的信号做拟合，画出的李萨如图形分别实现圆 直线 八字形

关于李萨如图形：
我自己做实验，
1.相位差决定形状，是直线/圆，椭圆
2.频率误差决定图形旋转速度，当基准频率小，相同的误差下速度快，反之速度慢
3.频率倍数/差决定周期，比如八字就是1:2的，2:1也一样，如果不改变相位的时候就是原图转90

因为这种图有对称的情况，所以我觉得是不是从中心搜没什么意义，是不是还是得从1k开始搜索
不过还有更好的办法，就是粗筛，先打几个点，比如1k 10k 100k 50k这种，看看长什么样，根据这种确定区间再找，很想二分了
或者dds快速扫频+图像评分

实际上这个题应该让搭建数字锁相环

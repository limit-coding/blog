# 视觉识别


下面按「人怎么看 + 程序用哪些量」说明每个 label 怎么判。特征来自轨迹点集，不是 OCR。

## 共用：先从二值图抽出一堆点

算这些量（大致）：

| 量 | 含义 |
|----|------|
| `aspect` | 长短轴比：细长 ≫1，圆 ≈1 |
| `ellipse_*` | 拟合单个椭圆好不好（残差、覆盖、内点） |
| `r_cv` | 到中心距离是否均匀：圆小，∞/线大 |
| `crossing` | 中心附近是否很密（∞ 交叉点） |
| `symmetry` | 左右/上下对称 |
| `line_residual` | 拟合成一条直线好不好 |

然后四个分数比大小，最高的就是 label。

---

## 1. `line`（斜线/对角线）

**想法**：像一根斜杠，不是闭合环，也没有中心交叉。

- 很长很瘦（`aspect` 很大），或
- 点几乎落在一条直线上（`line_residual` 很小）
- 不像闭合椭圆轨道；中心不太「打结」

**典型**：要求 1 的对角线；fy≈fx、相位 0°/180°。

---

## 2. `ellipse`（斜椭圆）

**想法**：一个闭合环，但明显拉长，不是正圆。

- 能较好拟合成**一个**椭圆
- 轴比大约在中间档（不太圆也不极端细）
- 中心交叉弱（不是 ∞）
- 径向变化中等

**典型**：同频、相位既不是 0° 也不是 90° 时的过渡态。

---

## 3. `circle`（圆 / 正椭圆）

**想法**：单个闭合环，横纵差不多，到中心距离差不多。

- 轴比接近 1
- 单个椭圆拟合好、绕一圈覆盖全
- `r_cv` 小（像圆环，不是两个叶）
- `crossing` 小（中心不该特别密）

**典型**：要求 2，fy≈fx、相位 ≈90°。题里允许横纵 div 不等，所以「正椭圆」也算这类。

**容易误判**：厚二值的 ∞，外轮廓也像圆 → 所以要靠 `r_cv` 高、有交叉来压掉假圆。

---

## 4. `infinity`（八字 ∞）

**想法**：不是一个环，是两个叶在中间交叉；外框可能像圆，但内部不均匀。

认 ∞ 主要靠：

1. **中心交叉** `crossing` 高（中间像打了结）
2. **径向不匀** `r_cv` 大（到中心有近有远，两叶造成）
3. **单个椭圆拟合差**（一个椭圆罩不住两个叶）
4. **对称**还不错（左右/上下对称的 ∞）
5. **不是直线**（`line_residual` 不能太好）

一句话：**外轮廓可以圆，但「中心打结 + 半径忽大忽小」→ 八字。**

**典型**：要求 3，fy≈2fx。

---

## 对比一览

```text
line      ：细长 / 直线拟合好 / 无闭合环
ellipse   ：一个拉长的闭合环
circle    ：一个接近圆的环，半径均匀，中心不打结
infinity  ：两叶 + 中心交叉 + 半径不均匀（即使外框像圆）
```

你刚才那张 ∞ 被判成圆，就是因为外框像圆、交叉在厚二值里偏弱；后来加强了「`r_cv` 高 + 有交叉 → 抬 ∞、压 circle」。

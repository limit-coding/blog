# 视觉算法


你这个思路整体是对的，而且你已经抓到了第五问真正的核心：
**摄像头不是单纯识别“现在像不像圆/直线/八字”，而是作为反馈传感器，利用李萨如图形的形状和运动趋势，闭环调节 DDS 的频率与相位。**
因此它确实可以叫**视觉锁频环 + 视觉锁相环**。但实现时，**定位频率**和**最终锁定**应该分成两个阶段，不能一开始就用 PID 硬追。
## **先回答你最后的问题：用照片还是视频？**
答案是：
**粗定位可以用单帧图像，精确锁频必须用视频或连续帧。**
因为单张照片只能告诉你：
* 图形大致是几比几；
* 有几个波瓣、交点；
* 当前是直线、椭圆、圆还是八字；
* 当前图形的主轴方向。
但单张照片无法可靠区分：
* 图形是在顺时针旋转还是逆时针旋转；
* 旋转速度有多快；
* 是频率偏高还是偏低；
* 图形是真正锁住了，还是刚好某一帧看起来符合目标。
而这些信息恰好是锁频最重要的误差信号。
所以你应该把摄像头当作一个低速动态传感器：

```
摄像头视频
   ↓
连续提取李萨如图形特征
   ↓
判断频率比例
   ↓
计算旋转方向、旋转速度、形状误差
   ↓
树莓派调整 FPGA DDS
   ↓
重新观察

```

不需要每一帧都做很重的识别。20～30 fps 已经足够做视觉反馈，因为你观察的不是 100 kHz 电信号本身，而是示波器屏幕上图形的慢速变化。

## **你关于李萨如图形的理解**
设：
[
x(t)=A\sin(2\pi f_x t)
]
[
y(t)=B\sin(2\pi f_y t+\phi)
]
## **1∶1 情况**
当 (f_x=f_y) 时：
* (\phi=0^\circ)：正斜线；
* (\phi=180^\circ)：反斜线；
* (\phi=90^\circ) 或 (270^\circ)，且两轴幅值相同：圆；
* 其他相位：椭圆。
这里你说得基本正确。
但要注意：
**固定频差主要导致图形持续变形或旋转；固定相位差决定锁定后最终停下来的形状。**
假设：
[
f_y=f_x+\Delta f
]
则相对相位为：
[
\Delta\phi(t)=2\pi \Delta f t+\phi_0
]
所以只要 (\Delta f\neq0)，相对相位就会不断变化，圆、椭圆、直线之间会周期性演化。你看到的“旋转”和“扭动”，本质上都是相对相位持续漂移。
相对相位转一整圈所需时间约为：
[
T_{\text{drift}}=\frac{1}{|\Delta f|}
]
例如：
* 频差 (10\text{ Hz})：约 0.1 秒循环一次，变化很快；
* 频差 (1\text{ Hz})：约 1 秒循环一次；
* 频差 (0.1\text{ Hz})：约 10 秒循环一次；
* 频差 (0.01\text{ Hz})：约 100 秒循环一次，看起来几乎不动。
这也解释了你们实验里频差减小后，图形逐渐稳定的现象。

## **2∶1、3∶1 等情况**
当频率比为：
[
f_y:f_x=m:n
]
且 (m,n) 互质时，会形成稳定闭合的多瓣李萨如图形。
你说的“2∶1 一个交叉，3∶1 两个交叉，4∶1 三个交叉”，在某些固定相位下确实容易观察到，但不建议把**交点数量**作为唯一判据，因为：
* 相位变化会让交点合并或分离；
* 线宽和屏幕余辉会导致交点粘连；
* 图形可能存在旋转、裁切、幅值不一致；
* 不同频率比在部分相位下可能出现相似投影。
更稳妥的是同时提取：
* 水平方向波瓣数；
* 竖直方向波瓣数；
* 极值点数量；
* 图形骨架的端点和分叉点；
* 主轴方向；
* 图形面积、圆度和长宽比。

## **为什么纯二分法不可靠？**
你怀疑二分法有问题是对的。
普通二分法要求存在单调误差，例如：

```
频率太低 → 误差为负
频率太高 → 误差为正

```

但李萨如图形的静态形状对频率不是单调映射。
例如目标是 20 kHz：
* DDS 发 10 kHz，形成 1∶2；
* DDS 发 40 kHz，形成 2∶1。
它们可能都是八字或双瓣形，只是方向、轴向和运动方式不同。再加上未知相位，仅靠一张图片很容易出现多解。
所以不能把“图形像不像八字”直接作为二分法的比较函数。
但是可以构造一个真正带方向的信息：
**短时间内主动改变 DDS 频率，然后观察图形漂移速度是变快还是变慢。**
这相当于用扰动做梯度判断。
假设当前 DDS 频率为 (f)，先测出图形运动速度 (v_0)，然后增加一个小量：
[
f'=f+\delta f
]
再测 (v_1)。
* 如果运动变慢，说明你向正确方向调整；
* 如果运动变快，说明方向错了；
* 反向调整即可。
这比依靠单帧方向稳得多。

## **我建议的完整算法**
## **第一阶段：快速粗搜索**
不要从 1 kHz 到 100 kHz 每 100 Hz 扫一遍，那是 991 个点，肯定太慢。
粗搜采用对数或分段采样，例如：
[
1,2,5,10,20,40,60,80,100\text{ kHz}
]
每个频率只观察约 100～200 ms，提取连续若干帧。
这一阶段不要求直接锁住，而是判断：
1. 当前图形是否出现较低阶的稳定结构；
2. 当前可能属于什么频率比；
3. 图形变化速度大不大；
4. 候选基频落在哪些区间。
但更好的办法是按题目允许的目标比例直接构造候选。
例如目标按钮要求：
* 圆或直线：需要 (f_y\approx f_x)；
* 八字：需要 (f_y\approx2f_x) 或 (f_y\approx f_x/2)。
那么观察到一个稳定的 2∶1 图形后，就能反推出未知频率大约是当前 DDS 的 2 倍或一半。然后通过图形朝向或一次主动扰动区分两者。
所以粗搜索的目标不是直接达到 100 Hz 精度，而是把范围从 1～100 kHz 缩小到一个很小的候选集合。

## **第二阶段：候选频率验证**
对于每个候选频率 (f_c)，分别测试：
[
f_c-\Delta,\quad f_c,\quad f_c+\Delta
]
比如先用：
[
\Delta=1\text{ kHz}
]
比较三个频率下的图形运动速度。
定义一个动态误差指标：
[
J(f)=\frac{1}{N-1}\sum_{k=1}^{N-1}
D(F_{k+1},F_k)
]
其中 (F_k) 是第 (k) 帧提取的图形特征，(D) 可以是：
* 图形主轴角度变化；
* 二值图轮廓差异；
* Hu 矩变化；
* 椭圆拟合参数变化；
* 骨架点集的距离。
(J(f)) 越小，说明图形越稳定，也就越接近整数频率比。
然后选三个点里 (J) 最小的方向继续缩小步长。
这其实是一维寻优，比普通二分法更适合。

## **第三阶段：逐级细化频率**
步长可以按以下层级递减：

```
1000 Hz → 200 Hz → 50 Hz → 10 Hz → 2 Hz → 亚赫兹微调

```

不一定每一级都完整扫描，只需要沿误差下降方向调整。
例如：

```
当前 70 kHz
试 69 kHz、70 kHz、71 kHz
发现 70 kHz 最稳定

再试 69.8、70.0、70.2 kHz
发现 70.2 kHz 更稳定

再试 70.15、70.20、70.25 kHz
……

```

最后不是依靠某一帧“看起来正确”，而是要求连续一段时间：
[
J(f)<J_{\mathrm{th}}
]
才能判断锁频成功。

## **锁频和锁相要分开**
这是非常重要的工程结构。
## **先锁频**
锁频阶段只关注：
* 图形是否持续旋转、变形；
* 旋转方向；
* 运动速度。
通过调整 DDS 频率，让运动速度趋近于零。
可以写成类似离散控制：
[
f_{k+1}=f_k-K_f e_f
]
其中 (e_f) 是带符号的漂移速度。
但初期不建议直接上标准 PID。原因是摄像头反馈：
* 帧率较低；
* 延迟不固定；
* 图像误差噪声大；
* DDS 调节后需要等待屏幕响应。
更适合：
**分级步长搜索 + 符号梯度控制 + 锁定后小步积分。**
接近锁定时再用 PI：
[
f_{k+1}=f_k-K_p\omega_k-K_i\sum\omega_k
]
这里 (\omega_k) 是图形主轴或相位特征的漂移速度。
一般不需要 D 项，视觉噪声经过微分后会被严重放大。

## **再锁相**
频率锁住后，图形基本不再持续运动，但它可能停在任意相位：
* 想要圆，当前可能是椭圆；
* 想要直线，当前可能是圆；
* 想要八字，当前可能是倾斜的八字。
这时调整 DDS 的初始相位：
[
\phi_{\text{DDS}}
]
根据不同按钮建立不同目标函数。
## **圆**
可以用椭圆拟合后的长短轴：
[
e_{\text{circle}}=\frac{|a-b|}{a+b}
]
同时考虑图形面积，防止误把短线判断成圆。
## **直线**
可以用二值图或轮廓点的协方差矩阵特征值：
[
e_{\text{line}}=\frac{\lambda_2}{\lambda_1}
]
越接近 0，越像直线。
再根据主轴角度区分正斜线和反斜线。
## **八字**
可以用模板距离，或者检测：
* 两个主要波瓣；
* 中央交叉区域；
* 图形上下或左右对称；
* 骨架分叉结构。
然后调相位使模板误差最小。

## **摄像头算法不必做得太复杂**
建议树莓派上的视觉流程：

```
固定 ROI
→ 灰度化
→ 背景扣除或阈值分割
→ 形态学去噪
→ 提取最大轮廓
→ 椭圆拟合 / PCA / 骨架特征
→ 多帧跟踪

```

不要一上来使用神经网络。这是高度规则化、背景固定的几何视觉任务，传统视觉更快、更稳定，也更容易解释误差。
## **多帧分析建议**
不要逐帧直接控制。可以每次取一个短窗口，例如：
* 摄像头 30 fps；
* 每次分析 6～10 帧；
* 时间窗口约 0.2～0.33 秒；
* 每调一次 DDS 后等待若干帧；
* 再计算新的运动误差。
这样系统虽然不是高速控制环，但对 10 秒内完成搜索完全有希望。


第一层：网格识别
确定屏幕边界、X/Y方向、中心位置，完成透视矫正

第二层：图形分离
去网格、二值化、形态学处理、提取曲线

第三层：静态分类
识别1:1、1:2、2:1、1:3、3:1等频率比例

第四层：候选推理
根据DDS当前频率，反推出未知频率候选集合

第五层：视频动态判断
比较连续帧，计算漂移速度和变化方向

第六层：调频
先大步、后小步，直到图形基本不再运动

第七层：调相
根据按钮要求调成圆、直线或八字

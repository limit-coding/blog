# 饱饭思淫欲循环


这个理论是我最近发现的，尤其在我破解自慰射精谜题以后发现的。
由于我前些天看了一些相亲视频激发我对一些事情的思考，这是最新的科研成果，尽情享受

当我现在没啥事，比较闲的时候，就开始饱饭思淫欲循环—想找女生玩，或者开始跟女生接触—然后接触以后关系好，有两种走向—1.跟女生找对象，然后找上以后发现生活很平淡且不如学习物理有有意思，且女生给我的魅力会随着时间指数下降，并且慢慢开始不满意 2.跟女生没找对象，然后被拉黑删除or 成为普通朋友泯然众人—然后回到不饱饭，开始干活以及压力—等干好了，开始饱饭思淫欲了

我研究了一下生命的起源，我觉得找对象繁衍有两种动力，这个是目前来说的。动力1 为了传宗接代和庇护所，类似于维护种族延续，和提升生存力和传承，自己40岁以后老了没有动力比0-40岁更好， 动力2。为了约会逛街，娱乐

当前来说有培育动力2的沃土，但是没有培育动力1的沃土，所以就算人有动力1的倾向往往会演化成动力2

有些人喜欢骗自己，就是把动力2伪装成动力1，但是多观察和研究激素含量变化自然发现是动力2

这个循环对我来说很重要，这是我解释为啥我5，11月喜欢跟女生聊天的循环，以及为啥我找对象觉得不如学习有意思的根本原因，本质上有虚无主义的意义在

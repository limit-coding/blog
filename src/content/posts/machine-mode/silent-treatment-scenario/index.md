# 冷暴力场景

故意冷处理或者已读不回，既解决不了任何问题，也显得挺幼稚的。既然我们的沟通频率不在一个层面上，那这次对话就到此为止，以后也不用费劲互相消耗了  有什么想法可以直接挑明，故意不回复除了显得沟通方式不够成熟、缺乏基本尊重之外，没有任何意义。
既然你习惯用这种方式处理人际关系，那我也不再打扰了，各自安好。这个不错

# 关于出行


我爸之前跟我说，我属于追求效率的人，所以按理说我应该比较喜欢开车、坐火车和坐飞机，因为这些方式比较快。

但是呢，我实际上是比较喜欢骑车的，骑车大于跑步，大于步行，大于那啥。

原因就是我实际上是一个追求控制感的人。骑车就是我能控制这个东西，开车就不能了，开车要受交管，但我骑车的话，这个实际上是步行的一个升级，但是开车可不是。

对的，所以我还比较愿意骑车去什么西安呀、骑车去什么德国呀啥的，但是不是太愿意开车去。你要如果我真真的让我去德国，我愿意坐飞机

对的，我觉得步行去德国绝对是傻逼，而且不太可能实现。但是骑车是有可能我骑车轻松马拉松破2，好吧

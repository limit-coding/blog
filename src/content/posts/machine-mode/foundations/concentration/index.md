# 人的定力问题


我觉得人会遇到很多社交的事情，举个例子
情况1.一个人社交圈小，稳定但是机会少，如果你的圈子小，精英多，那可以；如果不是，那你跳出来或者当领导很难
情况2.一个人社交圈大，那么你的定力从何而来，我就是情况2，因为我觉得人越多，那么我可以用的社会性节点就多，所以我必须要接受人多带来的舆论的问题，下面针对情况2进行论证

我设计了两套模式。
模式1.差序格局，按照心理学理论，人只能控制150个人，那么这150个人走差序格局，也就是核心圈，对你影响最大，同时能进入这个圈子必须是双向选择且门槛高，类似现在的常委，他们对你影响很大，他们说啥直接影响你的决策；按照这种，设计次核心圈，次次核心圈，普通人，可用的社会性节点，需要的时候激活，这个格局的话，他们的影响针对你自己就很小了

模式2.离散均匀格局，我们都是平等的，咱们都有相同的影响因子，那么如果现在找工作焦虑，就一起焦虑，现在考试焦虑，就一起焦虑；现在经济泡沫，大家一起经济泡沫，一起开心

我设计的就是，人同时有模式1和2，而且是有比例的，这个比例怎么设计每个人有区别，对于我来说就是我会保留常委，但是其他圈子其实不是很多，同时我有模式2，但是什么时候扩大模式1就是我发现噪声多的时候就开始建墙，这也是机器模式的一部分

我这个的关键就是，解释了定力是什么，我觉得定力不是唯心的，它不存在，而是一种结构，在这种结构里，他是有定力的，在模式2，就是没有定力的，如果你想有定力，选择模式1的比例增加；如果你现在不想有定力，选择模式2的比例增加
